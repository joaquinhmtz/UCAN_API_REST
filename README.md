# UCAN

El objetivo principal del proyecto es concentrar el inventario de distintas plataformas como Mercado Libre, Amazon, Shopify, etc.

## 📦 Tecnologías

- Node.js v19.7.0
- Express.js
- MongoDB 
- Mongoose (ORM)
- JWT, Bcrypt

## 🚀 Instalación

```bash
git clone https://github.com/AZTRAAI/UCAN_BACK.git
cd UCAN_BACK
npm install
cp .env.example .env
npm run dev       # Inicia el servidor en modo desarrollo con nodemon
